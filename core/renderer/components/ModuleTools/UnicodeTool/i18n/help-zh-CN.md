# Unicode

Unicode 是用于统一编码、表示和处理文本的国际标准。它为每个字符分配唯一编号，使文本可以在不同平台、设备、应用和语言之间稳定交换。

## 起源与发展

在 Unicode 出现之前，不同地区和系统使用大量互不兼容的字符编码。单一编码很难覆盖所有语言字符，也容易在跨平台传输时出现乱码。

Unicode 项目在 20 世纪 80 年代末开始，Unicode Consortium 于 1991 年成立并持续维护 Unicode 标准。

## 关键版本

- Unicode 1.0（1991）：首次发布，包含 7,161 个字符
- Unicode 3.0（1999）：包含 49,259 个字符
- Unicode 6.0（2010）：加入 Emoji
- Unicode 13.0（2020）：包含 143,924 个字符
- Unicode 15.0（2022）：包含 149,186 个字符

## 编码与实现

### 设计原则

Unicode 的核心设计目标包括：

- **通用性**：用统一字符集覆盖多种文字系统
- **效率**：便于解析、处理和存储
- **字符而非字形**：编码字符本身，而不是字体显示形态
- **语义明确**：每个字符有稳定语义
- **纯文本**：聚焦文本字符，不绑定样式
- **逻辑顺序**：内存中的文本按逻辑顺序表示
- **统一化**：合并不同文字系统中的重复字符
- **动态组合**：组合符号可与基础字符组合
- **稳定性**：已分配字符和语义保持稳定
- **可转换性**：可与其他字符集精确转换

### 常见 UTF 编码

- **UTF-8**：1-4 字节变长编码，兼容 ASCII，是 Web 上最常用的编码
- **UTF-16**：2 或 4 字节变长编码，Windows 和 Java 内部常用
- **UTF-32**：固定 4 字节编码，处理简单但空间占用更高

### 字符平面

Unicode 码位空间分为 17 个平面（0-16）。第 0 平面称为基本多文种平面（BMP），包含最常用字符。

## 输入方式

- **Linux**：按 `Ctrl+Shift+U`，输入 Unicode 十六进制码位
- **Windows**：按住 `Alt`，在小键盘输入 `0 + 十进制 Unicode 编码`
- **macOS**：启用 Unicode 十六进制输入法，按住 `Option` 输入码位
