# DevToolBox Docs

Project documentation for DevToolBox.

This repo contains project documentation, grouped by audience:

- Users (daily use)
- Marketplace plugin developers
- Core developers / contributors
- Governance and policies

## Layout

```text
docs/
├── index.md
├── users/
├── plugin-dev/
├── core-dev/
├── shared/
└── governance/
```

## Writing Guidelines

- Keep docs focused and task-oriented.
- Prefer relative links within this repo.
- Avoid embedding secrets or internal endpoints.
